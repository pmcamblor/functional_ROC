This folder contains supplementary material to the work:

"Using functional information for binary classifications" (Pablo Martinez-Camblor, 2026)

Particularly, it includes one .pdf document (Supplement.pdf) with 4 additionnal competitors to those provided in 
the main manuscript, and two alternative models, also some brief computational details. It also includes two .R files.
"simulations_10_competitors.R" provides the code used for generating the violin plot in the Monte Carlo simulations in 
both the main manuscript and the supplement. The file "simulations_ic.R" contains a more elaborate function for computing PBC
and evaluating the confidence interval performance. The two files contain an amount of overlap.
